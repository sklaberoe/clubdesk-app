# Публичен одит на ClubDesk

Дата на одита: 01.08.2026 г.

## Включени файлове

- `index.html` — самостоятелното HTML/CSS/JavaScript приложение.
- `PUBLIC_AUDIT.md` — този доклад.

В изходния проект няма manifest, service worker или отделни локални изображения, икони, CSS или JavaScript файлове, необходими за изпълнение. Единствената външна runtime зависимост е Supabase JavaScript v2, зареждана от HTTPS CDN.

## Лични и клубни данни

- Не са открити вградени списъци със състезатели.
- Не са открити вградени имена на състезатели, родители или тестови треньори.
- Не са открити телефонни номера или частни имейл адреси.
- Не са открити вградени записи за присъствия, плащания, календарни събития, архиви или миграционни резултати.
- Legacy масивите за състезатели, групи, графици и треньори са с празни стойности и не се попълват автоматично.
- Групите и състезателите се зареждат след удостоверяване от Supabase. Последно заредените Supabase данни могат да бъдат кеширани само в браузъра по време на работа и не са част от това публично копие.
- Присъствията, таксите и календарът остават локални за конкретния браузър. За администраторите е добавено ясно уведомление, че тези данни още не се синхронизират между устройства.

## Тайни и удостоверяване

- Не са открити `service_role` ключове, secret ключове, пароли за база данни, PostgreSQL connection strings, пароли на потребители, access tokens или refresh tokens.
- Налични са единствено Supabase Project URL и един браузърен publishable ключ: `sb_pub…62Jy`. Това е допустимият тип публичен frontend ключ.
- Supabase клиентът се създава точно веднъж.
- Приложението проверява сесията преди да покаже клубните данни и изисква валидно удостоверяване и активно членство.
- В копието няма предварително записани auth сесии. Сесиите могат да се създадат единствено в localStorage на браузъра след успешен вход.

## Пътища и GitHub Pages

- `index.html` се намира в корена на `public-build`.
- Не са открити локални `href`, `src`, `fetch` или service-worker пътища, започващи с `/`.
- Навигацията е hash-базирана и не изисква server-side routing.
- Няма локални asset пътища, които да се счупят при публикуване под `/clubdesk-app/`.
- Външният Supabase CDN адрес е абсолютен HTTPS URL и не зависи от project path.

## Проверки

- Проверени са всички файлове в `public-build` за лични имена, телефони, частни имейли, списъци със състезатели, присъствия, плащания, архиви, пароли, auth токени и привилегировани Supabase ключове.
- Проверени са всички inline JavaScript блокове: синтаксисът е валиден.
- Не са копирани backup HTML файлове, README, Git metadata или други development файлове.

Публичното копие е безопасно за публикуване.
